# 07 定语从句

> **大纲依据**：《成人高等教育本科生学士学位英语水平考试大纲（非英语专业）》（四）语法第 7 条要求"掌握基本的英语语法知识……各类从句的构成及其用法"；第 4 条要求掌握"常用连接词……的词义及其用法"。定语从句的关系代词、关系副词以及"介词 + which""as"等连接手段，正是第 7 条的考点。
> **真题分布**：共 4 题（真题（三）第42、43题，真题（六）第41题，真题（九）第39题），占 Part III 的 2%（4/200）。

## 一、考点定位：为什么这样考

定语从句的考题永远围绕一个问题：**先行词在从句中充当什么成分**。成分决定了用关系代词还是关系副词、用哪一个。200 道词汇语法真题中，定语从句命中 4 题，占比 2%。

4 题的考查点分布如下：

| 考查点 | 题号 | 答案 |
|---|---|---|
| 关系代词作从句宾语（先行词指物） | 真题（三）第42题 | that |
| 介词 + which 作状语 | 真题（三）第43题 | in which |
| as 引导非限制性定语从句（代替整个主句） | 真题（六）第41题 | as |
| the same … as 固定结构 | 真题（九）第39题 | as |

出题人设置干扰项的四套套路：

1. **关系副词误用**：从句缺宾语时给出 where / when（真题（三）第42题 A 项 where）。
2. **介词后误接 that**：介词 + that 不成立（真题（三）第42题 D 项 in that、真题（三）第43题 B 项 in that）。
3. **关系代词与从句内代词重复**：`that I want to visit it` 中 that 已作宾语，it 多余（真题（三）第42题 C 项）。
4. **用 what / that 冒充关系词**：what 从不引导定语从句；that 不能引导非限制性定语从句（真题（六）第41题）。

## 二、核心规则

### 1. 先判成分，再定关系词

| 先行词在从句中的成分 | 选用 | 例 |
|---|---|---|
| 主语 | that / which / who（不可省） | `This is the place that is worth visiting.` |
| 宾语 | that / which / whom / as（可省） | `The film (that) we saw last night was boring.` |
| 定语（所属） | whose | `I know the boy whose father is a doctor.` |
| 状语（时间/地点/原因） | when / where / why = 介词 + which | `I still remember the day when we first met.` |

**万能检验法**：把先行词塞回从句，看它占什么位置。塞回后作主语、宾语 → 用关系代词；塞回后必须加一个介词才通顺 → 用关系副词或"介词 + which"。

### 2. 只用 that 的场合

先行词为 all、everything、anything、nothing、much、little、none、the one 等**不定代词**；先行词被 the only、the very、the same、the last、**序数词**、**最高级**修饰；先行词**既指人又指物**；主句以 who / which 开头为避免重复。如：`All that glitters is not gold.`

### 3. 只用 which 的场合

引导**非限制性定语从句**；出现在**介词后**（in which / at which）；先行词是**整个主句**（用 which 指代上述内容）。如：`He was late again, which made his boss angry.`

### 4. 关系代词作宾语可省，作主语不可省

- 作宾语可省：`This is the place (that / which) I want to visit most.`
- 作主语不可省：`This is the place that / which is worth visiting.`
- 作宾语但**紧跟介词**时不可省：`the situation in which formal language is used`。

### 5. 介词 + 关系代词

介词的选择有两条依据：① 先行词的固定搭配（in the situation / in the case / at the rate / on the occasion）；② 从句中动词或形容词的搭配。`at the rate of` → `the rate at which …`。介词后只能用 which（指物）或 whom（指人），**不能用 that**。如：`This is the room in which he was born.`

### 6. as 引导（非限制性）定语从句

- as 作关系代词，可代替**整个主句**（也可代替一个名词），意为"正如"。位置灵活，可位于主句**前、中、后**：`As was expected, he came late.` / `He came late, as was expected.`
- 常见固定搭配：`as was to be expected`、`as is known to all`、`as is often the case`、`as has been said`、`as is reported`。`As is often the case, he forgot his keys.`
- as 指代整个主句时，从句谓语通常用**单数**。`The plan worked, as was hoped.`
- 与 which 的区别：which 从句只能位于主句**之后**，as 从句可前置；as 带"正如"的意味。`As you know, she has resigned.`

### 7. such … as 与 the same … as

| 结构 | 含义 | 例 |
|---|---|---|
| such + n. + as 从句 | 像……这样的（as 在从句中作成分） | Such people **as** you describe are rare. |
| the same + n. + as 从句 | 与……**同类**（未必是同一个） | This is the same knife **as** I lost yesterday. |
| the same + n. + that 从句 | 就是**同一个** | This is the same knife **that** I lost yesterday. |

## 三、真题精解

### 真题（三）第42题

- **题干/选项**：I have never been to New York, but it's the place ________.
  - A. where V d like to visit　B. that I want to visit most　C. that I want to visit it most　D. in that V d like to visit
- **答案**：B
- **译文**：我从未去过纽约，但这是我最想参观的地方。
- **解题思路**：
  1. 逗号前是完整句子，but 引出并列句；逗号后的 it 指代 New York，`the place` 是先行词。
  2. 数从句成分：`I want to visit most` —— visit 是及物动词，**缺宾语**（most 是程度状语），因此需要**关系代词**，而不是关系副词。
  3. 用"塞回检验法"：把 the place 塞回从句 → `I want to visit the place most`，place 作 visit 的宾语 → 用 that / which。四个选项中只有 B 是"关系代词 + 结构完整"的形式。
  4. 本题的关系代词作宾语，本来也可省略（`the place I want to visit most`），但只要有 that 同样正确。
- **干扰项分析**：
  - A. where：where 是关系副词，只能在从句中作状语；而本从句缺的是 visit 的宾语，where 补不上宾语。
  - C. that I want to visit **it** most：that 已经充当 visit 的宾语，从句里的 it 与之重复，宾语出现两次。
  - D. in that …：介词后**不能**用 that（只能用 which / whom）；而且 visit 仍缺宾语，介词 in 也无着落。
- **举一反三**：不要被 `it's … that …` 的外形误导成强调句——先行词是 the place，空格缺的是关系代词。区分 where 与 that/which 的唯一办法就是"塞回先行词，看它作状语还是作宾语"：`live in the place` → where；`visit the place` → that/which。

### 真题（三）第43题

- **题干/选项**：Government reports, examination compositions, legal documents and most business letters are the main situations ________ formal language is used.
  - A. at what　B. in that　C. on which　D. in which
- **答案**：D
- **译文**：政府报告、考试作文、法律文件和大多数商业信函都是使用正式语言的主要场合。
- **解题思路**：
  1. 先行词是 `the main situations`；从句 `formal language is used` 主谓结构完整（主语 formal language，被动谓语 is used）→ 说明从句**缺状语**，要用关系副词或"介词 + which"。
  2. 用塞回检验法：`Formal language is used **in** the situations.` 原句搭配是 in → 介词 in + 关系代词 which → `in which`（= where）。
- **干扰项分析**：
  - A. at what：what **从来不能引导定语从句**，且 at 与 situation 不搭配。
  - B. in that：介词后不能用 that；in that 本身是"因为"的连词，不引导定语从句。
  - C. on which：关系代词 which 用对了，但 situation 不与 on 搭配（应为 in the situation），介词选错。
- **举一反三**：介词 + which 中，介词由"原句搭配"决定。常见组合：`in the situation / in the case → in which`；`at the rate → at which`；`on the occasion → on which`；`for the reason → for which`。

### 真题（六）第41题

- **题干/选项**：A good many proposals were raised by the delegates, ________ was to be expected.
  - A. that　B. what　C. so　D. as
- **答案**：D
- **译文**：正如大家所预料的那样，代表们提出了许多建议。
- **解题思路**：
  1. 逗号后是一个从句，主语空缺，谓语是单数 was → 需要一个能作从句主语、且指代**整个主句内容**的关系代词。
  2. `as` 可代替整个主句，`as was to be expected` = "正如所预料的那样"，指代"A good many proposals were raised by the delegates"这一事实，作从句主语；指代整个主句视作单数，故用 was。
- **干扰项分析**：
  - A. that：that 不能引导非限制性定语从句（逗号隔开的从句一律不用 that）。
  - B. what：what 不是关系词，从不引导定语从句。
  - C. so：so 是副词或并列连词，不能充当从句主语引导定语从句。
- **举一反三**：牢记一组 as 引导的非限制性定语从句：`as was expected`、`as is known to all`、`as is often the case`、`as has been said`。与 which 的区别在于：`As was expected, he came late.`（as 从句可前置）/ `He came late, which was expected.`（which 从句只能后置）。

### 真题（九）第39题

- **题干/选项**：This is the same knife ________ I lost yesterday.
  - A. which　B. what　C. like　D. as
- **答案**：D
- **译文**：这像我昨天丢的那把刀。（与昨天丢的那把是同一款）
- **解题思路**：
  1. 题干含固定结构 `the same + 名词 + ___`，其后应接定语从句。
  2. `the same … as` 是固定搭配，意为"和……一样的"；从句 `I lost yesterday` 缺宾语，as 正好充当 lost 的宾语。
  3. the same … as 表示**同类**（不一定就是同一个）；若要表达"就是同一个"，才用 `the same … that`。
- **干扰项分析**：
  - A. which：语法上 `the same knife which` 不符合固定搭配，本结构习惯用 as。
  - B. what：what 不引导定语从句。
  - C. like：like 是介词或形容词，不能引导从句。
- **举一反三**：对比记忆：`This is the same pen as I lost.`（和丢的那支同款，不是同一支）/ `This is the same pen that I lost.`（就是丢的那支）。同类结构还有 `such … as`（as 在从句中作成分）：`Such books as he bought are all classics.`

## 四、易错点与陷阱清单

| 陷阱 | 表现 | 破解 |
|---|---|---|
| 关系副词误用 | 从句缺宾语却填 where / when | 塞回先行词，作宾语就用关系代词 |
| 介词后接 that | in that / at that 引导定语从句 | 介词后只能用 which / whom |
| 宾语重复 | that I want to visit **it** | 关系代词作宾语后，从句内不再用 it |
| what 冒充关系词 | 误把 what 当作 "先行词 + 关系词" 的合体 | 定语从句没有先行词就不用 what 引导 |
| 非限制性从句用 that | `, that was to be expected` | 逗号后的从句用 which / as，绝不用 that |
| as 与 which 位置 | 从句前置于主句却用 which | 前置的只能用 as（As is known to all, …） |
| the same 混淆 | the same … that 与 the same … as 同义处理 | as 表同类，that 表同一个 |

## 五、自测（举一反三）

1. This is the best film ________ I have ever seen.
   A. which　B. that　C. as　D. what
2. The house ________ we live is very old.
   A. which　B. that　C. in which　D. who
3. He is the only person ________ can help you.
   A. which　B. who　C. whom　D. what
4. ________ is known to all, the earth moves around the sun.
   A. It　B. As　C. Which　D. That
5. I'll never forget the day ________ we first met.
   A. which　B. that　C. when　D. where
6. The book, ________ cover is red, belongs to Mary.
   A. which　B. whose　C. that　D. what
7. Everything ________ he said was true.
   A. which　B. what　C. that　D. as
8. Such people ________ you describe are rare.
   A. that　B. which　C. as　D. what

### 答案与解析

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | B | 先行词被最高级 best 修饰，关系代词只能用 that。 |
| 2 | C | 从句 `we live ___` 缺地点状语，live 与 in 搭配（live in the house）→ in which（= where）。 |
| 3 | B | 先行词 person 指人且在从句中作主语 → who（若选项有 that 亦可）。 |
| 4 | B | 非限制性定语从句代替整个主句且**前置**，只能用 as。 |
| 5 | C | 先行词 the day 在从句中作时间状语 → when。 |
| 6 | B | 表示"书的封面"这一所属关系 → whose。 |
| 7 | C | 先行词为不定代词 everything，关系代词只能用 that。 |
| 8 | C | 固定结构 such … as，as 在从句中作 describe 的宾语。 |
