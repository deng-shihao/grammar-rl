# 08 状语从句与连词

> **大纲依据**：《成人高等教育本科生学士学位英语水平考试大纲（非英语专业）》（四）语法第 7 条要求"掌握基本的英语语法知识……各类从句的构成及其用法"；第 4 条要求掌握"常用连接词……的词义及其用法"。状语从句连接词的选择（时间、条件、让步、结果、目的、方式）正是这两条要求的直接落点。
> **真题分布**：共 7 题（真题（二）第42题，真题（四）第39、49题，真题（七）第47题，真题（八）第33、48题，真题（九）第42题），占 Part III 的 3.5%（7/200）。

## 一、考点定位：为什么这样考

状语从句在 Part III 中的考法有两种：一是**给一个空白，四个选项是语义各异的连词或连词短语**，要求根据逻辑关系（时间、让步、结果、目的、方式）选择；二是**给一个连词，四个选项是同一从句的不同语序或时态**，要求从句用陈述语序、且时间/条件/让步状语从句用一般现在时表将来。200 道词汇语法真题中，状语从句与连词命中 7 题，占比 3.5%，是三个从句考点中题量最多的。

7 题的逻辑类型分布如下：

| 逻辑类型 | 题号 | 答案 |
|---|---|---|
| 方式（as if） | 真题（二）第42题 | as if |
| 结果（such … that） | 真题（四）第39题 | that |
| 让步（whether … or not） | 真题（四）第49题 | Whether you like it |
| 让步（however much） | 真题（七）第47题 | the dictionary costs |
| 目的（so that + 情态动词） | 真题（八）第33题 | could |
| 时间（the instant） | 真题（八）第48题 | the instant（原书答案 in an instant 存疑） |
| 时间（the moment） | 真题（九）第42题 | the moment |

出题人设置干扰项的三套套路：

1. **同形近义连词短语混排**：as regards / as to / as for / as if 一字之差、语义全非（真题（二）第42题）。
2. **语序与时态陷阱**：让步从句给疑问语序（does the dictionary cost）或用将来时（will cost）（真题（七）第47题）。
3. **介词短语冒充连词**：in an instant / for an instant 只是时间状语，却被放在需要从属连词的位置（真题（八）第48题）。

## 二、核心规则

### 1. 引导状语从句的常用连词一览

| 逻辑关系 | 常用连接词 | 例句 |
|---|---|---|
| 时间 | when / while / as / before / after / since / until / till / once / as soon as；名词性连接词 the moment / the instant / the minute / the second / immediately / directly / instantly | We left as soon as the rain stopped. |
| 条件 | if / unless / as long as / so long as / in case / provided (that) / on condition that | You will fail unless you work harder. |
| 让步 | although / though / even if / even though / no matter how (what, who…) / however / whatever / whoever / whether … or not | Although it was late, he kept working. |
| 结果 | so + adj./adv. + that；such (+ a/an + adj.) + n. + that | It was so hot that we stayed indoors. |
| 目的 | so that / in order that + 从句；so as to / in order to + 动词原形 | She spoke slowly so that we could follow her. |
| 方式/比较 | as if / as though；as；than | She acted as if nothing had happened. |

### 2. 时间状语从句

- **"一……就……"的连接手段**：as soon as；`the moment / the instant / the minute / the second (that) + 陈述句`；immediately / directly / instantly；hardly … when；no sooner … than（后两者需倒装）。`Hardly had I sat down when the phone rang.`
- **while 与 the moment 的区别**：while 引导**持续性**动作（常与进行时或延续性动词连用）；the moment / the instant 强调**瞬间**，与瞬间动词连用。`While I was cooking, the phone rang.`
- **主将从现**：时间、条件、让步状语从句中，用**一般现在时**代替一般将来时。`If it rains tomorrow, we will stay at home.`

### 3. 让步状语从句

- `however + 形容词/副词 + 主语 + 谓语` = `no matter how + 形容词/副词 + 主语 + 谓语`，从句用**陈述语序**。`However cold it is, he swims every day.`
- `no matter what / who / where / when` = whatever / whoever / wherever / whenever。`Whatever you say, I will not change my mind.`
- `whether … or not` 表让步"无论……与否"，从句用陈述语序（不可倒装）。`Whether you agree or not, I will keep trying.`
- as / though 引导让步从句时，表语或状语可提到句首构成倒装（`Strong as he is, …`）。`Young as she is, she is very brave.`

### 4. 结果状语从句：so … that 与 such … that

| 结构 | 构成 | 例 |
|---|---|---|
| so … that | so + 形容词/副词 + that | It is `so` difficult `that` no one can solve it. |
| so … that | so + 形容词 + a/an + 单数可数名词 + that | `It was so hot a day that we stayed indoors.` |
| such … that | such + a/an + 形容词 + 单数可数名词 + that | `It was such a good film that I saw it twice.` |
| such … that | such + 形容词 + 复数/不可数名词 + that | `They were such difficult problems that nobody solved them.` |
| so … that | so + many/much/few/little + 名词 + that | `There were so many people that we couldn't get in.` |

### 5. 目的状语从句

- `so that` / `in order that` 引导目的状语从句，从句中常用情态动词 can / could / may / might / will / would；主句是过去时，从句通常用 could / would / might。`She locked the door so that nobody could enter.`
- `so as to` / `in order to` 后接**动词原形**，不接从句。`She whispered so as not to wake the baby.`
- 区分 `so that`（表目的，其后直接跟从句）与 `so … that`（表结果，so 后必须有形容词/副词）。`He spoke so fast that nobody understood him.`

### 6. 方式状语从句与 as 短语

- `as if` / `as though` 意为"仿佛、好像"，后可接：① 从句（常用虚拟语气）；② 不定式（as if to do）；③ 分词；④ 形容词或介词短语。`He talks as if he knew everything.`
- 易混短语：as regards / as to / as for 都是"关于、至于"，后接**名词（短语）**；as if 是连词，后接从句或不定式。`As for me, I prefer coffee.`

## 三、真题精解

### 真题（二）第42题

- **题干/选项**：When Tom was about to speak, his father looked at him, ________ to stop him.
  - A. as regards　B. as to　C. as for　D. as if
- **答案**：D
- **译文**：当汤姆要说话的时候，他爸爸看着他，好像要制止他一样。
- **解题思路**：
  1. 空格前 `his father looked at him` 已是完整句子，空格后是不定式 to stop him，需要一个**能接不定式的从属连词**来补充说明"看"的态度。
  2. `as if to do` 是固定说法，意为"仿佛要……"，语义与"看着他要制止他"吻合 → D。
- **干扰项分析**：
  - A. as regards：介词短语"关于、至于"，后接名词，不接不定式。
  - B. as to：意为"至于、关于"，同样只接名词（短语）。
  - C. as for：意为"至于、就……而言"，也只接名词（短语）。
  - 三项词义与结构都不符合"看着他想制止他"的语境。
- **举一反三**：`as if / as though` 的四种后续形式要记牢：`He opened his mouth as if to say something.`（+不定式）/ `He looks as if he were ill.`（+虚拟语气从句）/ `He stared at me as if seeing a ghost.`（+分词）/ `He stood there as if dead.`（+形容词）。

### 真题（四）第39题

- **题干/选项**：It's such a difficult problem ________ no one can work it out.
  - A. as　B. that　C. so　D. thus
- **答案**：B
- **译文**：这个问题如此之难，没人可以解决。
- **解题思路**：
  1. 空格前是 `such a difficult problem`，构成 `such … that …` 的固定搭配，表示"如此……以至于"。
  2. 空格后的从句 `no one can work it out` 结构完整（no one 主语，can work 谓语，it 宾语），只能由引导结果状语从句的 that 连接 → B。
- **干扰项分析**：
  - A. as：`such … as` 引导定语从句时，as 必须在从句中充当成分（作主语或宾语）；本从句不缺成分，而且句意是"结果"而非"定语"。
  - C. so：so 修饰形容词或副词，不能说 `so a difficult problem`（须说 `so difficult a problem`）。
  - D. thus：副词，不能引导从句。
- **举一反三**：记住等价转换：`so difficult a problem` = `such a difficult problem`。注意 `so many / so much / so few / so little + 名词 + that` 用 so，其余"such + 名词"结构用 such。

### 真题（四）第49题

- **题干/选项**：________ or not, you are going to face him one day.
  - A. If you like it　B. Whether you like it　C. However you like it　D. Whether do you like it
- **答案**：B
- **译文**：无论你喜不喜欢，总有一天要面对他。
- **解题思路**：
  1. 空格后紧跟 `or not`，与从句一起构成让步状语从句"无论你喜不喜欢"。
  2. `whether … or not` 是表让步的固定结构，从句一律用**陈述语序** → `Whether you like it or not` → B。
- **干扰项分析**：
  - A. If you like it：if 不能与 `or not` 直接搭配表让步，if 只引导条件从句。
  - C. However you like it：however 表让步时，后面必须紧跟形容词或副词（however hard you try），不能直接接"主语 + 谓语"。
  - D. Whether do you like it：让步从句用陈述语序，`do you like` 是疑问语序，错误。
- **举一反三**：`whether … or not` / `whether or not` / `whether … or …` 都能表让步：`Whether rich or poor, she loves him.` / `Whether or not it rains, we'll go.`

### 真题（七）第47题

- **题干/选项**：However much ________, it will be worth the money.
  - A. the dictionary costs　B. costs the dictionary　C. the dictionary will cost　D. does the dictionary cost
- **答案**：A
- **译文**：不管这本词典花多少钱，它都是物有所值。
- **解题思路**：
  1. `However much …` 相当于 `no matter how much …`，引导**让步状语从句**；however much 修饰 costs（花多少钱）。
  2. 让步状语从句用**陈述语序**（主语 + 谓语）→ `the dictionary costs`。
  3. 而且让步状语从句用**一般现在时**代替将来时，尽管主句是 `it will be worth`，从句仍用 costs，不能用 will cost → A。
- **干扰项分析**：
  - B. costs the dictionary：主谓倒装，语序错误。
  - C. the dictionary will cost：语序正确，但状语从句中不能用 will 表将来，时态错误。
  - D. does the dictionary cost：疑问语序，错误。
- **举一反三**：`however` 与 `no matter how` 完全等价，从句一律"陈述语序 + 一般现在时表将来"：`However hard he tries, he can't win.` / `No matter how late it is, she keeps working.`

### 真题（八）第33题

- **题干/选项**：I wrote down the number so that I ________ remember it.
  - A. might　B. should　C. could　D. needed
- **答案**：C
- **译文**：我写下了号码，以便能记住它。
- **解题思路**：
  1. `so that` 引导**目的状语从句**，表示"以便"。
  2. 目的状语从句中常用情态动词 can / could / may / might / will / would。主句谓语 wrote 是过去时，从句应选过去形式。
  3. 从句语义是"我**能**记住它"，强调能力，用 could 最贴切 → C。
- **干扰项分析**：
  - A. might：意为"许可、可能"，与"记住需要的能力"语义不符。
  - B. should：意为"应该"，不能表达目的。
  - D. needed：need 作情态动词后接动词原形且不用于肯定句，needed 是实义动词过去式，后面不能直接跟 remember。
- **举一反三**：`so that`（目的，后直接跟从句）与 `so … that`（结果，so 后必须有形容词/副词）不要混：`He got up early so that he could catch the bus.` / `He got up so early that he caught the bus.`

### 真题（八）第48题

- **题干/选项**：You see the lightning ________ it happens, but you hear the thunder later.
  - A. the instant　B. for an instant　C. on the instant　D. in an instant
- **答案**：D（原书答案；本题语法存疑，见下）
- **译文**：闪电发生后，你可以马上看到，但是稍后才能听到雷声。
- **解题思路**：
  1. 空格后是完整的 `it happens`，空格前是完整句子 `You see the lightning`，两句话之间**必须有一个能引导时间状语从句的从属连词**，否则句子不成立。
  2. 表"一……就……"的名词性连接词 `the instant (that)` = as soon as，正好承担这个连接作用：`You see the lightning the instant it happens.`（闪电一发生你就看到它），语义与下文"雷声要晚一些才听到"形成对比 → 语法上应选 A。
- **干扰项分析**：
  - A. the instant：能引导时间状语从句，是语法上正确的选项。
  - B. for an instant：介词短语"一会儿"，只作时间状语，不能连接从句。
  - C. on the instant：介词短语，不能连接从句。
  - D. in an instant：介词短语"立刻、马上"，同样只能作状语；若填入，则 `You see the lightning in an instant it happens` 中 it happens 与前句之间没有任何连接手段，句子不成立。
- **举一反三**：能表达"一……就……"的手段：`the instant / the moment / the minute / the second` + 陈述句；`as soon as`；`immediately / directly / instantly`；`hardly … when`；`no sooner … than`。

> **存疑**：本题原书答案为 D（in an instant），但空白后是完整句子 it happens，该位置需要一个能引导时间状语从句的从属连词；in an instant 是介词短语，只能作状语，无法连接从句，填 D 后 it happens 无着落。按语法，正确答案应为 A（the instant = as soon as）。疑原书答案有误。

### 真题（九）第42题

- **题干/选项**：I was so familiar with her that I recognized her voice ________ I picked up the phone.
  - A. the moment　B. since　C. before　D. while
- **答案**：A
- **译文**：我和她太熟了，以至于我一接起电话就能辨认出她的声音。
- **解题思路**：
  1. `so … that …` 引导结果状语从句；that 从句内部 `I recognized her voice ___ I picked up the phone` 又含一个时间状语从句。
  2. 语义是"我一接起电话就认出她的声音"，pick up the phone 是**瞬间动作** → 用表瞬间的 `the moment (that)`（= as soon as）→ A。
- **干扰项分析**：
  - B. since：意为"自从"，主句须用完成时，且与"接电话"这一瞬间事件语义不合。
  - C. before：意为"在……之前"，与"一接电话就认出"的语义相反。
  - D. while：强调"在……期间"的**持续性**动作，常接进行时；而 pick up the phone 是瞬间动作，不能与 while 搭配。
- **举一反三**：瞬间 vs 持续：`while` 配延续性动词/进行时（while I was reading）；`the moment / as soon as` 配瞬间动词（the moment I saw him）。

## 四、易错点与陷阱清单

| 陷阱 | 表现 | 破解 |
|---|---|---|
| 形近短语混排 | as regards / as to / as for 被当成 as if | 看后面接名词还是从句/不定式 |
| 连词与介词混淆 | 在需要连词处填 in an instant / for an instant | 从句需要从属连词，介词短语只能作状语 |
| 语序陷阱 | 让步从句写疑问语序（does he cost） | 状语从句一律陈述语序 |
| 时态陷阱 | 时间/条件/让步从句用 will | 主将从现，从句用一般现在时 |
| so 与 such 误用 | `so a difficult problem` | so + adj.；such + a/an + adj. + n. |
| so that 与 so … that 混淆 | 目的/结果错位 | so that 后直接跟从句；so … that 中 so 后必须有形容词/副词 |
| while 与 the moment 误用 | 瞬间动作前用 while | 持续用 while，瞬间用 the moment/the instant |
| if 冒充 whether | `If you like it or not` | 让步"无论是否"只能用 whether … or not |

   A. so　B. such　C. very　D. too

   A. than　B. when　C. while　D. since

   A. so that　B. so as to　C. in order to　D. such that

   A. can　B. might　C. must　D. need
8. No matter how ________, he never gives up.
   A. hard is it　B. hard it is　C. it is hard　D. hard does it
9. You may go out ________ you finish your homework first.
   A. as long as　B. as soon as　C. so that　D. even if
10. It looks ________ it is going to rain.
    A. even if　B. as if　C. so that　D. in case

| 题号 | 答案 | 解析 |

| 3 | B | `hardly … when` 为固定搭配，意为"刚……就……"。 |
| 4 | A | 前后为让步关系"虽然……却" → Although。 |

| 7 | B | 目的状语从句 + 主句过去时，情态动词用 might（in order that he might not fall）。 |
| 8 | B | `no matter how + adj. + 主语 + 谓语`，用陈述语序 → hard it is。 |
| 9 | A | "只要你先做完作业" → as long as 引导条件状语从句。 |
| 10 | B | "看起来好像要下雨了" → as if 引导方式/表语从句。 |
